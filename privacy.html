Privacy policy

Last updated: 7 November 2026.

My Channel YT is a personal tool. Its only user is the owner of the YouTube channel it publishes to.

What it accesses

  • With youtube.upload, it uploads videos the owner made to the owner's channel and sets their thumbnails. Every upload is private.
  • With youtube.readonly, it reads the processing status of those uploads, so it knows when a thumbnail can be set.

It does not read comments, subscribers, analytics, other videos, or any data from other accounts.

Where the data stays

The sign-in token is stored in a file on the owner's own computer and is never sent anywhere except to Google when the tool calls the YouTube API. The tool has no server and no database, and it does not collect, sell or share Google user data with anyone.

The use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends it.
